# Data-Science-Salary-Analysis

📊 Data Science Salary Analysis Dashboard
Project Overview

This project analyzes Data Science salaries from 2020–2022 across multiple countries, experience levels, company sizes, and work arrangements.

Objectives
Understand salary trends
Analyze the impact of experience
Compare remote and on-site salaries
Identify top-paying roles
Explore geographical differences
Tools Used
Microsoft Excel

Key Insights
Executive-level professionals earn 3.2x more than entry-level professionals.
Fully remote positions pay approximately $16,000 more than on-site positions.
Salaries increased by 30% between 2020 and 2022.
Leadership positions command the highest compensation.
