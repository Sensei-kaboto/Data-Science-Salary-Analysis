# Data-Science-Salary-Analysis

# 📊 Global Data Science Salary Analysis Dashboard

## 🚀 Project Overview

This project explores the global Data Science job market using salary data collected between **2020 and 2022**. The analysis focuses on identifying salary trends, understanding the impact of experience levels, evaluating remote work compensation, and examining geographical differences in Data Science salaries.

The project was developed entirely in **Microsoft Excel** using data cleaning techniques, Pivot Tables, Pivot Charts, Slicers, KPI Cards, and Dashboard Design principles.

---

## 🎯 Business Problem

The Data Science industry has experienced rapid growth over the past few years. Organizations and professionals need to understand:

* Which Data Science roles offer the highest salaries?
* How does experience impact compensation?
* Do remote jobs pay more than on-site jobs?
* Which countries provide the highest earning opportunities?
* How have salaries evolved over time?

This analysis aims to answer these questions through data-driven insights.

## 📈 Key Findings

### 1. Experience Significantly Impacts Salary

| Experience Level | Average Salary |
| ---------------- | -------------: |
| Entry-Level      |        $61,643 |
| Mid-Level        |        $87,996 |
| Senior-Level     |       $138,617 |
| Executive-Level  |       $199,392 |

Executive-level professionals earn more than **3 times** the salary of entry-level professionals.

---

### 2. Salaries Increased Rapidly Between 2020 and 2022

| Year | Average Salary |
| ---- | -------------: |
| 2020 |        $95,813 |
| 2021 |        $99,854 |
| 2022 |       $124,522 |

Average salaries increased by approximately **30%** during the period analyzed.

---

### 3. Fully Remote Positions Offer Higher Compensation

| Work Arrangement | Average Salary |
| ---------------- | -------------: |
| Fully Remote     |       $122,457 |
| On Site          |       $106,355 |
| Partially Remote |        $80,823 |

Remote positions offered the highest average salaries.

---

### 4. Leadership Roles Command Premium Salaries

Top-paying roles include:

* Data Analytics Lead
* Principal Data Engineer
* Principal Data Scientist
* Director of Data Science
* Data Architect

These positions combine technical expertise with leadership responsibilities.

---

### 5. Location Plays a Major Role in Compensation

Some of the highest-paying countries include:

* United States
* New Zealand
* Israel
* Japan
* Canada

Geographical location remains one of the strongest salary determinants.
